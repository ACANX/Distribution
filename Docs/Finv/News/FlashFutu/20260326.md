飞书官方目前没有提供“导出为 Markdown”的按钮，但借助开源社区的工具可以轻松实现。根据你的技术背景和需求，主要有三种方案可选：

| 方案类型 | 核心工具 | 特点 | 适合人群 |
| :--- | :--- | :--- | :--- |
| **浏览器插件** | Cloud Document Converter  | ✅ 操作简单，右键即用<br>✅ 无需代码基础<br>✅ 支持复制/下载 | 轻度用户，偶尔转换单篇文档 |
| **命令行工具** | feishu2md <br>feishu-doc-export <br>grodoc  | ✅ 格式保真度高<br>✅ 支持批量转换<br>✅ 可集成到自动化流程 | 开发者、技术运营，需批量/精确转换 |
| **Node.js 库** | doc2markdown  | ✅ 编程集成<br>✅ 灵活定制（如图片处理） | 开发者，需在自己的项目中调用 |

---

### 方案一：浏览器插件（最简单，推荐首选）

如果你只是偶尔需要转换一两篇文档，不想折腾代码，这个插件是最佳选择。

1.  **安装插件**：在 Chrome 应用商店搜索 **Cloud Document Converter** 并安装。
2.  **打开文档**：在浏览器中打开你想要导出的飞书文档。
3.  **右键导出**：在文档页面任意位置点击鼠标右键，找到 `Cloud Document Converter` 选项，然后选择 **“下载为Markdown”** 或 **“复制为Markdown”** 即可。

这个插件能较好地支持标题、代码块、表格、图片等常见格式的转换。

---

### 方案二：命令行工具（最强大，支持批量）

如果你需要转换大量文档，或者对格式保真度有极高要求，推荐使用命令行工具。

这类工具的原理是通过飞书官方API获取文档数据，再解析并生成Markdown文件。通常需要几个步骤：

1.  **创建飞书应用并获取凭证**（所有命令行工具都需要此步骤）：
    -   访问 [飞书开放平台](https://open.feishu.cn/)，创建一个“企业自建应用”。
    -   在应用的“权限管理”中，开通与云文档相关的权限，例如 `docx:document:readonly` 和 `drive:drive` 等。**注意：权限列表可能有分页，需要仔细检查确保都已开通**。
    -   在“版本管理与发布”中发布应用，并等待管理员审核（如果是测试企业，通常自动通过）。
    -   最后，在应用的“凭证与基础信息”页面，获取 `App ID` 和 `App Secret`。

2.  **选择合适的工具**：
    -   **追求高质量转换**：选择 **feishu2md**。它直接解析飞书API返回的数据结构，转换为Markdown，格式保真度最高。但需要为每个文档单独执行命令。
        ```bash
        # 示例命令
        feishu2md dl "你的飞书文档链接" -o "输出目录"
        ```
    -   **需要批量备份整个知识库**：选择 **feishu-doc-export**。它支持一键导出整个知识库或文件夹，并完美保留原始目录结构，实测导出700份文档约25分钟。
        ```bash
        # 示例命令（导出为Markdown）
        ./feishu-doc-export --appId=你的AppID --appSecret=你的密钥 --exportPath=输出目录 --saveType=md
        ```
    -   **希望配置更简单**：选择 **grodoc**。它将配置过程简化为一个YAML文件，可以集中管理多个文档和版本，对AI工具链用户很友好。

---

### 方案三：Node.js 库（最灵活，用于集成）

如果你是一名开发者，希望在自己的脚本或工具中实现“飞书文档 → Markdown”的自动化转换，可以使用 `doc2markdown` 这个库。

在你的Node.js项目中安装并调用它，可以灵活地控制转换过程，例如批量处理、自定义图片的存储路径和处理逻辑等。

### 常见问题：导出的Markdown中图片无法显示？

这是正常现象。飞书文档中的图片链接通常需要权限验证才能访问。

-   **部分工具已内置解决方案**：如 `feishu-doc-export` 和 `doc2markdown` 等工具支持自动将图片下载到本地，并更新Markdown文件中的链接为本地路径。
-   **如果使用其他工具**：你可能需要手动处理或编写脚本，将图片链接替换为可访问的地址。

总结一下：**技术小白或偶尔使用，首选浏览器插件；需要进行批量备份或对格式要求极高，推荐使用命令行工具；想深度集成到自己的工作流中，可以尝试Node.js库。**
